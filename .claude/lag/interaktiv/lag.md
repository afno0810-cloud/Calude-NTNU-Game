# Lag: Interaktiv verden

## Fokus
Gjør Helgasetr levende og ødeleggbart: dører og glassdører (med kodelås som kan dirkes eller brytes),
glass som knuses (vinduer, glassvegger, glassbokser, rekkverk), kulehull som blir værende, lettvegger, dører og
møbler som kan sprenges, løse ting som kan plukkes opp, bæres, kastes, veltes og ødelegges (stoler, puffer,
flasker, brannslukkere), barrikader, skap som kan åpnes, lysbrytere, heiser, kiosk/kjøleskap, piano,
bordtennis, skjermer. Alt replikert for online, realistisk, og ytelsesvennlig.

## Filer laget eier
`GSMapState.*` (tilstand for dører/glass/ødelagte ting, replikert), `GSDoor.*`, `GSBreakable.*`, `GSPhysicsProp.*`, `GSInteract.*` (felles «bruk»-grensesnitt), og nye modeller for interaktive ting i `Tools/Blender/interactive*.py`. Se tabellen i `.claude/lag/LAG.md`.
Trenger laget endringer i andre lags filer: bestilling i `.claude/lag/bestillinger.md`.

## Mappen
Alle lagets planer, vurderinger, logg, funn og retning ligger i `.claude/lag/interaktiv/`.
